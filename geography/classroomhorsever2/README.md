# Classroom Horse Race – GitHub Pages

Teacher-controlled classroom race board.

## Rules
- 16 race spaces plus a separate START position.
- Correct answer: **+2**.
- Mistake: **+1**.
- Teacher can move a horse back one space with **↩** if a button is pressed accidentally.
- Choose 2–12 teams; only those horses appear.
- Teams do not need to answer at the same speed. The teacher controls each horse independently.

## Files
- `index.html` – the complete app
- `assets/horses/horse1.png` … `horse12.png` – individual horse artwork

## GitHub Pages
Upload the contents of this folder to a GitHub repository. In **Settings → Pages**, choose **Deploy from a branch**, select the branch containing `index.html`, and save.
