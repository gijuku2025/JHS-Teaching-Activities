# Classroom Horse Race

A simple static horse-race game for classroom use.

## Rules
- 16 spaces.
- Correct answer: move the team's horse +2.
- Mistake: move +1.
- Supports 2–12 teams.
- The teacher controls movement with buttons.
- The game is designed for a projector/Keynote-style classroom display.

## GitHub Pages
This is a plain HTML/CSS/JavaScript site, so it can be hosted directly with GitHub Pages. GitHub Pages can publish static HTML, CSS, and JavaScript from a repository.

Put `index.html` and the `assets` folder in your repository, then enable GitHub Pages from the repository's Settings → Pages.
